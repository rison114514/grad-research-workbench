设置

AI 模型配置 · GitHub Token · 本地数据管理

AI 服务配置
支持 OpenAI 兼容接口。默认保留约 32K tokens 历史；可按模型能力调整，数值越大，请求耗时与费用可能越高。DeepSeek V4 可设置更高预算，但还需为系统提示、工具定义和模型输出预留空间。
Agent 个性化资料
仅将这里主动填写的字段加入 Agent 上下文；API Key、GitHub Token、Zotero 凭据及本地路径不会提供给模型。
GitHub 配置
不配置也可匿名使用（限 60 次/小时）。获取：GitHub → Settings → Developer settings → Tokens。
Zotero 只读同步
只读取条目、分类和标签；不会修改或删除 Zotero 中的任何内容。Library ID 可在 Zotero API Keys 页面查看。
文献界面
文献列表、详情与分类树的字号三档切换；三栏宽度可在文献页拖动分隔条调整、点击栏头 ◀ 折叠。
桌面宠物
点击宠物可展开聊天框与 AI 助手对话；自定义头像需选择本地图片（PNG/JPG，限 5MB）。
本地数据
数据以 JSON 文件本地存储，可随时备份或迁移。
