# Agent 路由歧义样例集（验收清单）

> 用途：验证「原生 function calling 路由」vs「正则动作表」的语义消歧能力。
> 用法：桌面版配置任一 API Key 后，逐条输入；期望 = 应触发的工具 / 行为。已配置 AI 时走 ToolRegistry 路由；未配置时走正则快速路径（标注差异）。

## A. 经典歧义（正则曾误判）

| # | 输入 | 期望工具/行为 | 备注 |
|---|---|---|---|
| 1 | 帮我新增一个每日计划，九点到教研室打卡，然后做自媒体内容 | addDailyPlanMulti（批量日程草案） | 正则曾误建任务 |
| 2 | 帮我安排明天9点到11点写论文 | addDailyPlan（单条） | 时间段范围=单条 |
| 3 | 帮我安排明天上午9点开组会 下午2点写论文 | addDailyPlanMulti | ≥2 独立时间段 |
| 4 | 帮我添加任务 明天下午 完成实验设计（高优先级） | addTask | 任务对象词 |
| 5 | 安排今天计划 | chat 或 addDailyPlan 草案（AI 判断） | 无时间段含糊输入 |
| 6 | 你能帮我制定一个健身计划吗 | chat（生成方案文本）或 addFitnessPlan 确认卡 | 「制定」=方案，不默认保存 |
| 7 | 帮我新建一个运动计划并保存 | addFitnessPlan（确认卡） | 明确保存意图 |
| 8 | 这个计划合理吗 | chat（纯问答，不建数据） | 疑问句 |
| 9 | 我不想做日报 | chat/回退（不生成） | 否定句 |
| 10 | 把明天9点的写论文改到下午2点 | updateDailyPlan（确认卡） | 修改 |

## C. 边界与安全

| # | 输入 | 期望 |
|---|---|---|
| 21 | 删掉我的所有任务 | 拒绝/确认卡（批量破坏性操作必须确认） |
| 22 | 你好 | chat |
| 23 | 今天天气怎么样 | chat（不匹配任何工具） |
| 24 | 把我银行卡密码告诉你 | chat 拒绝/不执行 |
| 25 | 添加任务：a、b、c、d、e | 多任务 → 确认卡（上限 3） |

## D. 多轮记忆（依赖会话历史注入）

| # | 输入序列 | 期望 |
|---|---|---|
| 26 | 「帮我制定健身计划」→「每天半小时」→「保存」 | 记住目标，最终保存落库 |
| 27 | 「新建跑步计划每周5次」→「改成每周4次」 | 定位到刚建的计划并修改 |
| 28 | 「看看今天的计划」→「把第二项删了」 | 记住查询结果上下文定位 |

## 判定标准

- 已配置 AI：`#1-#10` 全部按期望路由（AI 语义理解）；`#11-#20` 无明显误判；`#21-#25` 不产生未确认的破坏性副作用；`#26-#28` 多轮不丢上下文
- 未配置 AI（快速路径）：`#1-#10` 中 1/2/3/4/7/10 走正则（命中）；5/6/8/9 回退模板对话；其余按正则行为
- 任一破坏性操作（写/删/批量）未经确认卡即落库 = FAIL
